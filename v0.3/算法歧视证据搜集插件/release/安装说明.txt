算法歧视众包观测 · Edge 插件安装与使用说明
==================================================

一、安装到 Edge
--------------------------------------------------
1. 把 zip 文件（算法歧视观测-edge插件-vX.X.X.zip）解压到一个固定目录
   （例如 D:\extensions\algo-observer\），解压后该目录第一层应直接看到
   manifest.json；不要再多套一层文件夹。
2. 打开 Edge，地址栏输入 edge://extensions 回车。
3. 打开左侧/左下角的「开发人员模式」开关。
4. 点击「加载已解压的扩展程序」，选择刚才解压的目录。
5. 扩展列表中出现「算法歧视众包观测」即安装成功，建议点击其
   「详细信息 → 在工具栏中显示」把图标固定到工具栏。

二、首次使用流程
--------------------------------------------------
1. 先启动本地后端（见第五节），保持其运行。
2. 打开淘宝 / 天猫 / 京东 / 拼多多网页版的任一商品详情页。
3. 点击工具栏上的扩展图标，在弹窗中：
   ① 阅读授权说明，点「同意并参与」（仅授权一次，之后不再提示）；
   ② 在「后端连接」区点「测试连接」，显示绿色「已连通（数据库正常）」
      说明后端就绪；红色报错时请按提示先启动后端；
   ③ 点「采集本页数据」，提示「已上报」即完成一条观测。
4. 弹窗内「📊 打开本地控制台」可打开浏览器页面，查看数据库
   内容与歧视分析看板；「📊 数据报告」查看本机已采集记录的图表。

三、自动采集开关（可选）
--------------------------------------------------
- 位置：弹窗「授权状态」卡内的「商品页自动采集」开关，
  或设置页「授权」区的同名开关，两处实时同步。
- 前提：必须先完成授权（同意并参与），否则开关为禁用状态。
- 效果：打开后，在淘宝等支持平台的列表页/首页点击商品链接进入
  商品详情页时，只要能提取到数据就自动采集上报，页面右上角会弹出
  「✅ 已自动采集本页观测数据」3 秒提示，无需手动点工具栏按钮。
- 去重：同一商品 10 分钟内不重复自动采集（手动采集不受限）。
- 隐私：自动采集同样在本地脱敏后上报，内容与手动采集完全一致。
- 说明：自动触发时无用户点击手势，页面截图可能失败，记录中会标注
  screenshotError，其余字段不受影响。

四、默认配置
--------------------------------------------------
- 上报端点：http://127.0.0.1:8000/api/observations
- API Key（X-API-Key 请求头）：dev-key-123
- 以上均可在扩展「设置」页修改（弹窗右下角 ⚙️ 设置）。

五、本地后端启动命令
--------------------------------------------------
在 backend 目录下执行：

    cd backend
    uvicorn app.main:app --port 8000

启动后扩展的「测试连接」应显示绿色连通；控制台地址为
http://127.0.0.1:8000/

六、增强抓取说明（v0.3.0）
--------------------------------------------------
- 价格、发货地、店铺等字段现在走「双通道」提取：先读页面 DOM 节点，
  读不到再自动从页面内嵌的初始化数据（__INIT_DATA / g_config 等）回退，
  适应淘宝/天猫新版页面结构，抓空率显著降低。
- 到手价只在页面确实有券后价时记录；没有优惠价时该字段为空（null），
  不再用售价顶替，便于区分原价与折扣价。
- 发货地同时保留原文（如「浙江 嘉兴」）与归一化城市（「嘉兴」）；
  店铺除名称外还会尽量提取店铺 ID。
- 已按真实 2025 版页面结构做适配（v0.3.4）：到手价取高亮价格容器、原价取
  优惠前容器（无优惠商品到手价记空、不顶替）、发货地按「至」取发货侧、
  店铺名自动剔除评分后缀；页面价格模块是异步渲染的，插件会等待最多约
  8 秒再判定；完全抓不到价格时该条记录不上报，弹窗会提示
  「未抓取到价格，已取消上报」，刷新页面后重新采集即可。
- 已用三个高仿真模拟页做回归验证（jsdom 执行真实编译产物）：
    模拟页A（天猫 982252700443，双价结构）：原价 3799、到手价 3188.55、
      浙江嘉兴→嘉兴、天猫国际自营全球超级店、shopId 2212833764123 —— 全部命中
    模拟页B（天猫 651981565426，双价结构+data-shopid）：原价 18.7、到手价 15.74、
      重庆→重庆、厮磨工坊旗舰店、shopId 889977665 —— 全部命中
    模拟页C（淘宝 836035130704，无优惠价+店铺名清理）：原价 3850、到手价 空、
      广东深圳→深圳、明智电脑科技、shopId 110245678 —— 全部命中

七、数据没传到面板？（失败重试与排查）
--------------------------------------------------
采集时若后端不可达或返回错误，数据不会丢失：记录会先保存在浏览器
本地并标注「上报失败」，弹窗会显示具体错误原因。按以下顺序排查：
1. 弹窗「后端连接」区点「测试连接」：
   - 红色「无法连接」类提示 → 后端没启动。双击项目根目录的
     「启动本地服务.bat」，或手动执行第五节的 uvicorn 命令；
   - 提示 401/403 → 设置页里的 API Key 与后端不一致；
   - 提示 422 → 后端校验未通过，弹窗会显示后端返回的具体原因。
2. 弹窗底部出现「有 N 条记录待重试」卡片时，点「重试上报」：
   插件会把本地已存的失败记录原样重新上报（不重新截图/提取），
   成功后显示「重试 N 条：成功 X 失败 Y」。
3. 仍然失败：确认后端终端窗口没有报错、端口 8000 未被其他程序
   占用，然后回到第 1 步重试。

八、隐私说明（简要）
--------------------------------------------------
- 仅采集商品页公开展示的商品名、价格、优惠、发货地，以及脱敏后的
  登录/会员状态、设备与网络环境概况；
- 绝不采集账号密码、cookie 值、订单与支付信息、浏览历史；
- 昵称/店铺名默认打码（如「张*」），可在设置页调整；
- 所有记录同时保存在浏览器本地，可在设置页一键清空；
- 自动采集仅在您明确授权并主动打开开关后才会发生。
