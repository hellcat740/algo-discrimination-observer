# 启动说明

## 拿到压缩包后

你会拿到两个压缩包：

* **系统压缩包**（前端插件系统，内含 `启动本地服务.bat`）

* **backend 压缩包**（后端服务）

解压时让两个文件夹放在**同一级目录**下，例如：

```
某文件夹/
├─ 算法歧视证据搜集插件/      ← 系统（启动脚本在这里面）
└─ backend/                ← 后端（或保持 backend.zip 不解压也行）
```

## 启动（只需一步）

双击系统文件夹里的 **`启动本地服务.bat`**。

脚本会自动完成：

1. **完整性自检** —— 如果系统里缺少 `backend` 文件夹，会自动从上一级目录复制 `backend` 文件夹，或直接解压上一级的 `backend.zip`；
2. **环境准备** —— 首次运行自动创建 Python 虚拟环境并安装依赖（需已安装 Python 3.10+，安装时勾选 Add to PATH）；
3. **启动服务** —— 启动后端并自动打开浏览器访问 <http://localhost:8000/。>

看到「服务已启动」提示后即可关闭该窗口；后端在【算法歧视观测后端】窗口中运行，**关闭那个窗口即停止服务**。

##

常见问题

| 问题                    | 解决办法                                                   |
| --------------------- | ------------------------------------------------------ |
| 提示找不到 backend 且无法自动修复 | 确认 backend 文件夹或 backend.zip 与系统文件夹在**同一级目录**           |
| 提示未找到 Python          | 安装 Python 3.10 及以上（python.org 或微软商店），安装时勾选 Add to PATH |
| 端口被占用提示               | 说明服务已在运行，直接访问 <http://localhost:8000/> 即可              |
