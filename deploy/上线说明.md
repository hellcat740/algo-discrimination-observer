## 让国内能直接点开：绑定自定义域名（唯一剩余步骤）

1. 买一个域名（任意平台，约 ¥60/年），或用手头已有的。
2. Vercel 项目 → **Settings → Domains** → 输入如 `observer.你的域名.com` → Add。
3. 到域名服务商的 DNS 解析处，按 Vercel 提示加一条记录：
   - 子域名（如 observer）：`CNAME` → `cname.vercel-dns.com`（或页面给出的目标值）
   -  apex 域名（如 xxx.com）：按提示加 `A` 记录
4. 等待解析生效（几分钟到几小时），Vercel 自动签发 HTTPS。
5. **把新域名告诉我**，我把插件内置服务器地址改成新域名并重新打包（插件 zip 在 `api/app/static/plugin.zip`，需要同步替换）。

## 数据通路（v0.4.2：本机数据 ⇄ 服务器双向流动，全链路已本地实测）

**服务器侧接口**（已在公网服务上线，`/api/pool/*`，X-User-Id 鉴权）：

| 接口 | 作用 |
| --- | --- |
| `POST /api/pool/sync` | 本地后端批量上行本机采集的观测；按 observation_id 幂等判重，可安全重试 |
| `GET /api/pool/observations?product_id=…` | 按商品拉取全池匿名化数据（user_ref 假名化为 `u_<sha256[:10]>`，可按"用户"分组但无法反推身份） |
| `GET /api/pool/products?keyword=…` | 发现服务器上有哪些商品可拉（≥2 条样本才列出） |

**管理员用户管理**（`/api/admin/*`，管理员密钥，服务器与本地后端均已上线）：

| 接口 | 作用 |
| --- | --- |
| `GET /api/admin/users` | 列出全部匿名用户（活跃时间、观测数）——管理员看板可看到所有用户的数据 |
| `DELETE /api/admin/users/{anonymous_id}` | 删除该用户全部观测与建档 |

控制台 UI（服务器 `/console` 与本地后端同源）：总览页「服务器同步」卡片（待同步/已同步 +
「立即上行」按钮，未配置服务器时灰色兜底）、歧视分析页「拉取服务器同商品数据合并比对」+
「保留拉取数据到本地（keep)」复选框、观测数据页「用户 / 来源」列与「👥 用户管理」抽屉（增删已齐）。

**本地后端**（`deploy/repo/backend`，研究员/团队用）：

```bash
# 1. 配置环境变量（Windows: set 变量=值；PowerShell: $env:变量="值"）
set SYNC_SERVER_URL=https://你的域名        # 公网服务器地址（双击 启动本地服务.bat 时默认已设为
                                            # https://algo-observer-server.vercel.app，可预先 set 覆盖）
set SYNC_USER_ID=你的匿名UUID              # 上行身份（缺省取本库最早用户）
set SYNC_INTERVAL_SEC=300                  # 自动上行周期，默认 300 秒

# 2. 启动本地后端：后台线程会自动周期上行（"收集到的数据自动上传到服务器"）
#    Vercel 环境（VERCEL=1）自动禁用该线程，防止服务器自我同步回环
uvicorn app.main:app --port 8000
```

- 手动立即上行：`POST http://127.0.0.1:8000/api/local/sync/push`
- 同步状态：`GET /api/local/sync/status`（待同步/已同步/已留存数量）
- **拉取比对分析**（分析时自动拉服务器相关商品数据，与本机合并判别）：
  - API：`POST /api/local/analysis/pull`，body `{"product_id":"…","keep":false}`
    — `keep=false`（默认）：分析完即删，服务器数据不留存本机；
    `keep=true`：以 `origin='pulled'` 留存本机，可随时重分析。
  - CLI：`python -m analysis.cli --pull-from https://你的域名 --product-id … [--keep]`
    （CLI 会先自动上行本机待同步数据，再拉取合并分析）
- 管理员控制台「观测数据」页新增 **＋ 新增记录**：手动补录线下样本，走同一清洗管线。
